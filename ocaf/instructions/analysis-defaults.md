# OCAF Analysis Defaults

When working in an unfamiliar directory:

- infer project purpose from small files and structure first
- identify likely languages, workflow systems, and execution environments
- detect script directories, config files, manifests, and workflow entrypoints
- identify likely large-artifact directories such as `data/`, `results/`, `output/`, `processed/`, `logs/`, `checkpoints/`, `models/`, and `artifacts/`
- produce a concise project summary, likely current stage, and suggested next scaffolding step

When bootstrapping:

- keep the initial scaffold minimal
- prefer generic templates over domain-specific boilerplate
- preserve the user's existing style and conventions when they are already established
