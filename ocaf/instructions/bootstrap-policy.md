# OCAF Bootstrap Policy

- `/analysis-prep` should inspect and recommend by default, not scaffold automatically.
- `/analysis-init` should create the minimal project-local framework only after project structure has been reviewed.
- Do not assume every project is bioinformatics.
- Keep the core framework generic and modular.
- Add domain-specific skills only when the project clearly benefits from them.
- If the directory already contains agentic-analysis files such as `AGENTS.md`, `STATUS.md`, `.opencode/`, or planning templates, preserve them and integrate minimally.
